Выпускаю Lanka — красивые презентации с вашими AI-агентами, внутри компании.

Подключаете агента через MCP, описываете задачу и дорабатываете слайды в браузере. Шаблоны Focus помогают с дизайном, коллеги оставляют комментарии, а предложения агента можно посмотреть перед принятием.

Документы остаются в общей библиотеке с папками и историей. Когда нужен файл — есть PDF и редактируемый PowerPoint.

Lanka можно развернуть на своих серверах. Есть подключение Codex к чату редактора; Claude Code и корпоративные MCP-агенты могут работать через инструменты. Для других встроенных чатов может понадобиться адаптер.

Это первый public preview. Бесплатно для компаний, Apache 2.0.

Ищу команды, которые хотят попробовать на своих задачах — предложения клиентам, отчёты, внутренние презентации. Напишите мне.
