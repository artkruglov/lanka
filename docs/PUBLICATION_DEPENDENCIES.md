# Шрифты и сведения о опубликованной версии

Откройте публикацию и выберите «Шрифты и сведения о версии». ZIP содержит файлы использованных шрифтов, их лицензии и manifest.json: номер исходной версии, хэш пакета, идентификатор сборки рендерера, версию Node, хэши PDF/PPTX/превью и зависимостей документа.

PDF использует встроенные шрифты. В PPTX шрифты не встроены; для редактирования с исходным начертанием они должны быть установлены в используемой среде. ZIP не устанавливает их автоматически и не содержит исполняемый образ рендерера. Он сохраняет файлы шрифтов и сведения о происхождении экспортов, но сам по себе не гарантирует одинаковое отображение в любых версиях PowerPoint.

Комплект сохраняется при публикации и не пересобирается при скачивании. Доступ проверяется так же, как к самой публикации. У старых публикаций, созданных до внедрения комплекта, ссылка отсутствует; их существующие файлы сохраняются.

Для администратора: новая версия использует миграцию 0030_publication_dependencies. Она разрешает дополнительный тип неизменяемого артефакта в прежнем хранилище. Выполняйте стандартное обновление схемы перед запуском нового runtime; старые SQL-миграции не изменены. Применение миграции не дописывает отсутствующие комплекты к старым публикациям.
