# Повторная сверка редакторов и OSS — 0.5

5 сентября 2026. Проверены исходные ссылки PRD и текущие официальные README репозиториев. Это сверка заявленных возможностей и фактических зависимостей нашего кода, не полный построчный аудит восьми codebase. Репозитории не импортировались целиком. Точные неоднозначные ссылки PPTMaster/pptx-viewer не подменялись произвольно найденными проектами.

Да, готовое ручное редактирование существует. Ограничение нашего интерфейса возникло из реализации review-first и предыдущего уточнения о запрете inline-правок, а не из отсутствия open source редакторов. Исходные PRD при этом содержали managed-light direct edit: v1.2 §7.3/PR-REV-006 и v2.0 PR-EDIT-001.

## Что изменено сейчас

Собственная панель свойств управляет тем же типизированным Slide AST, который рендерится в SVG/PDF/PPTX. Добавлены прямые поля, автосохранение с проверкой ревизии, сохранение нового ввода при ответе на предыдущую запись, undo/redo и состояние конфликта. Для этого не копировался PPTist или новый upstream-код. Сохранена исходная модель proposals для изменений агента.

Если нужен полнофункциональный Keynote canvas, следующий шаг — ограниченный технический spike двух кандидатов: CreatPPT и Presenton. Вход: текущий AST и несколько реальных корпоративных слайдов. Выход: работающий вертикальный сценарий text/image/chart → edit → canonical save → render/export, таблица потерь и лицензии точного commit. PPTist включать в сравнение после решения о допустимости AGPL, а не представлять его как уже выбранную зависимость. Принять reuse можно только по результату этого сценария.
