## Открыть и повторно запустить

Сервис слушает только `127.0.0.1:4317`.

- [Библиотека](http://127.0.0.1:4317)
- [Цивилизации: города, письмо и связи](http://127.0.0.1:4317/documents/7534ae80-b420-45e3-9933-83a56762a101) — 6 слайдов, версия 4.
- [Шёлковые пути: товары и идеи](http://127.0.0.1:4317/documents/7534ae80-b420-45e3-9933-83a56762a102) — 4 слайда, версия 2.

Для фонового запуска на macOS из корня репозитория: `npm run start:local:background`. Процесс управляется launchd и не завершается вместе с задачей агента или терминалом. Остановка: `npm run stop:local`, пересборка и перезапуск: `npm run restart:local`, состояние: `bash scripts/local-server.sh status`. Регистрация действует в текущем сеансе macOS; автозапуск после выхода из аккаунта или перезагрузки не установлен. Логи: `work/local-server/stdout.log` и `stderr.log`.

Запуск в открытом терминале: `npm run start:local`. Альтернативный порт: `PORT=4318 npm run start:local`. Требуются Node ≥22.13 и npm. Скрипт собирает MCP/редактор, устанавливает зависимости только при их отсутствии. Сборка приложения для локального редактора не требует Cloudflare.

Пользовательские данные: `work/local-library/library.json` и `work/local-library/documents/<id>/project.json`. Они игнорируются Git. Копировать для резервной копии нужно всю папку `work/local-library` при остановленных писателях, включая `materials` и `revisions`. Удалять `work` для очистки сборки нельзя.

`npm run demo:history` создаёт две демонстрации через stdio MCP. Повторное создание идемпотентно и не заменяет правки в существующих документах. На другом порту задайте `LANKA_ORIGIN`, для другой библиотеки — `LANKA_WORKSPACE`. Авторизация, ключи и сессии Codex в пакет документов не включаются.

## Что изменилось

Библиотека содержит карточки с обложками, поиск, папки, перемещение, переименование папок и корзину с восстановлением. Название презентации редактируется в заголовке редактора. Каждый документ получает собственный MCP root: агент одного документа не обнаруживает соседние.

Редактор: слайды слева, большой холст в центре, содержание/комментарии/подключение агента справа. Есть добавление, удаление и перестановка слайдов, отмена/повтор ручных правок, сохранение (в том числе Cmd/Ctrl+S), показ с клавиатурой, PDF/PPTX. Нажатие на текст Focus 3 переводит к соответствующему полю; свободной геометрии нет. Сохранение явное, автоматическое сохранение не реализовано.

Ожидающие предложения видны на карточке документа и над холстом. Сравнение показывает старый/новый текст с цветовым выделением и два слайда. Неизменённая логика скрыта. На мобильном экране переход из ответа агента переключает видимую панель. Принятие работает по выбранным слайдам целиком; отдельные поля одного слайда пока не принимаются независимо.

История включает ручные сохранения, принятые предложения и восстановление. Снимки канонического документа имеют SHA-256; manifest с указателями фиксируется атомарно вместе с текущим состоянием. Восстановление добавляет новую ревизию. Неподтверждённые файлы от прерванной записи не становятся версиями. История не является полным журналом комментариев/ACL: это снимки содержимого. Для импортированных старых проектов история начинается с первой локальной операции, прошлое не выдумывается.

## Реальный Codex

Через установленный Codex App Server подтверждён существующий managed ChatGPT вход. Авторизация проверяется `account/read`; OAuth и токены остаются под управлением Codex согласно [официальному протоколу](https://learn.chatgpt.com/docs/app-server). Скрипт не читает и не копирует credentials.

Вызвана реальная модель, выбранная как default из `model/list` (`gpt-6-astra` в этой проверке). Результат проходит существующий `ProjectReviewSession`: замечание человека → типизированные операции → MCP proposal → MCP reply. Вызов не менял основной документ. Все настроенные MCP были отключены в процессе модели, встроенные инструменты отключены адаптером; зафиксировано отсутствие вызовов инструментов моделью. Запись предложения выполнял ограниченный проектом клиент после проверки результата.

Та же persistent-сессия восстановлена после перезапуска процесса. Следующий ход отменён, а `thread/read` подтвердил terminal status `interrupted`. Повторный проход review вернул idle без дубликата. Доказательство: `out/local-review/codex-live.json`; воспроизводящий live-тест `scripts/verify-local-codex.mjs` рассчитан на свежий демо-сценарий с непрочитанным замечанием и существующим входом владельца.

Затем предложение реальной модели принято кликом в мобильном браузере; связанный комментарий решён. Для самостоятельной проверки владельца оставлены новые pending-предложения: одно в каждом документе. В деке о путях уже принято одно из двух изменений, второе ожидает решения.

Встроенный постоянно работающий чат/worker в редакторе **не запущен**. Вкладка «Агент» честно показывает это и выдаёт MCP-конфигурацию конкретного документа. Текущая live-проверка использовала личный локальный вход Codex; это не завершённая корпоративная авторизация облачного worker. Production runtime сохраняет свои требования к выделенному home и credentials.

## Скорректированная очередь

Локальная библиотека и основной review-проход реализованы. Следующие P0: перенести этот понятный UX в облачный редактор; подключить из него ограниченную документом сессию со стадиями/cancel/resume и реальным входом; затем организации/права и межклиентская изоляция. Требуются многопользовательская приёмка и реальные политики организации.

Частично выполнены foundations этапов 3 и 5: одноуровневые локальные папки, content history, partial accept по слайдам. Не завершены наследуемые корпоративные права, приглашения/отзыв, блоки со стабильными IDs, комментарии к блокам, принятие отдельных полей, автоматическое разрешение конфликтов, извлечение Brand Library из материалов клиента, неизменяемая публикация/manifest, backup drill и мониторинг пилота. Локальная папка/корзина не является границей доступа для внешнего процесса с файловыми правами.
