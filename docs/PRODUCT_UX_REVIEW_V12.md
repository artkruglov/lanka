# Проверка пользовательских сценариев Lanka — 5 сентября 2026

## Вывод от лица нового клиента

Продукт пока нельзя считать законченным рабочим местом «открыл презентацию → попросил своего Codex → увидел правки → принял → поделился». Реализованные механизмы разнесены между облачным редактором, облачными задачами и локальным проектом. Интерфейс недостаточно объяснял эту границу. Восстановление локального worker из V11 не подключило его к левому блоку облачного сайта.

Это независимая от прежнего списка выполненных работ проверка кода, маршрутов и контрактов. Это **не живое пользовательское тестирование**. Облачный браузер ранее получил запрет доступа к внутреннему preview; опубликованные Sites URL не поддерживаются браузером этой среды. Повторного обхода ограничения не выполнялось. Запрос Sites с include_mcp_connection подтвердил: опубликованный Site не объявляет подключаемый MCP-сервер.

## Подтверждённые проблемы и внесённые исправления

| Действие пользователя | Что мешало | Изменение |
| --- | --- | --- |
| Найти созданную презентацию | Стартовая страница открывала задачи | Домашняя страница открывает презентации; задачи остаются доступны |
| Понять «Выпуски» | Термин без очевидной цели; инструкция ссылалась на исчезнувшую вкладку «Агент» | «Утверждённые версии», пояснение неизменяемой копии, правильный путь через «Проверка» |
| Вернуться из утверждённой копии в документ | Передавался отсутствующий tab=agent | Старый маршрут открывает существующую панель проверки |
| Исправить выбранный текст | Весь SVG был одной кнопкой выбора слайда | В Focus 2 текстовые примитивы имеют явную семантическую привязку. Клик или Enter/Space открывает соответствующий input справа |
| Исправить показатель/ячейку | Не было связи объекта с формой | Отдельные привязки к ID метрики и её значению/единице/подписи, к строке/колонке таблицы, к подписи/значению диаграммы |
| Увидеть результат агента | Обновление отбрасывалось при расхождении revision | Обновляется список предложений без замены документа и базы несохранённых правок |
| Найти готовое предложение | Только статус выполнения | Кнопка «Посмотреть изменения», уведомление с переходом, баннер на слайдах, ручное обновление предложений |
| Найти ранее принятые изменения | Показывались только pending | История рассмотренных предложений с до/после; это сравнение в текущем шаблоне, не архивный пиксельный снимок |
| Подключиться к своему Codex | Блок воспринимался как уже подключённый чат | Явно показано отсутствие сессии; при ненастроенном помощнике ввод отключён и объяснён доступный обмен пакетами |

Визуальная геометрия шаблонов не менялась. Выбор текстовых элементов добавлен в Focus 2; старые дизайны пока редактируются через общую форму справа. Изображения, столбцы графика и декоративные фигуры не получили свободного позиционирования. Текст меняется в боковой панели, не через contenteditable поверх SVG.

## Следующий обязательный продуктовый этап

Единый облачный цикл: открыть сохранённую презентацию → выбрать подключение клиента → увидеть состояние соединения → отправить задачу/комментарий → наблюдать этапы → получить proposal → сравнить на том же экране → принять → увидеть сохранённый результат. Соединение должно быть ограничено организацией, проектом и пользователем, поддерживать отзыв прав и не давать агенту утверждать публикацию.

Левый блок показывает подключение, задачу, ход работы, вопросы и результат. Центр показывает текущий слайд или сравнение. Правая панель редактирует выбранный смысловой элемент. «Утверждённые версии» вторичны относительно ежедневной работы с документами.

## Ручной приёмочный сценарий перед релизом

1. Открыть домашнюю страницу: найти существующий документ, открыть постоянную ссылку, обновить страницу без потери документа.
2. В Focus 2 нажать заголовок, тело, метрику и ячейку; убедиться, что справа фокус на точном поле, включая одинаковые строки в разных блоках. Повторить клавиатурой.
3. Изменить текст, дождаться сохранения, перезагрузить. Проверить undo/redo и сохранение при ошибке сети.
4. При неподключённом агенте проверить честный статус; убедиться, что интерфейс не обещает работающий чат Codex.
5. Получить предложение, открыть до/после, принять один слайд, найти результат в истории. Изменить слайд вручную до принятия старого предложения и проверить конфликт.
6. Проверить появление предложения после изменения серверной версии, сохранив введённый локально текст.
7. Создать утверждённую копию, изменить оригинал, проверить неизменность копии.
8. Повторить просмотр/редактирование с ролями editor/reviewer/viewer и на мобильном экране. Реальные пользовательские и браузерные результаты пока не получены.
