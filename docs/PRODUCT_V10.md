# Lanka v0.10 — Focus 2

## Результат

Сейлз-презентация переработана через локальный MCP: создание документа, предложение изменений, применение разрешённой пользователем правки через сервис редактора, lint и экспорт. В ней 11 слайдов, без изображений и без выдуманных результатов клиентов. Полная проверка работы авторизованной модели Codex не выполнялась.

Открываемый пример: `/examples/lanka-sales-focus-v2`. Первое открытие создаёт личный сохранённый документ; последующие возвращают его с правками. Для совместной работы нужно поделиться ссылкой самого документа и выдать доступ. Ссылка примера у другого сотрудника создаёт его собственную копию.

## Критика и изменения

| Проблема предыдущей версии | Изменение |
| --- | --- |
| Тонкая синяя линия почти не создавала акцента | Синее поле обложки, шапка таблицы, финальное действие |
| Заголовки и пояснения выглядели как увеличенный текстовый документ | Полужирные заголовки, компактная верхняя строка, более явная иерархия |
| Рассказ об агентной правке не показывал, что изменилось | Конкретное сравнение «План пилота» / «Начнём пилот с одной команды» |
| Соседние таблицы повторяли одну композицию | Готовность к внедрению представлена тремя задачами; таблица оставлена для критериев |
| Качество зависело от разового оформления деки | Версионированные токены, рецепты, примеры и общий рендерер Focus 2 |

## Изменения продукта

- `focus-v2` — новый дизайн по умолчанию. Focus 1, его сцена и исходная демонстрация не изменены.
- Общая сцена поддерживает все десять композиций для браузера, PDF и PPTX. Шрифты автоматически не уменьшаются.
- Агент через `get_authoring_guide` получает контракты обеих версий и правило: в Focus 2 по умолчанию нет изображений, сгенерированные иллюстрации не используются.
- Галерея показывает реальные композиции; пустая рамка с несуществующим изображением исключена из примеров Focus.
- Новый демонстрационный документ использует отдельную идентичность, чтобы сохранить предыдущие пользовательские правки.

Политика происхождения изображений является инструкцией для агента и рецензента. Сервер не определяет, сгенерирован ли загруженный PNG/JPEG. Этот релиз не добавляет такой детектор.

## Проверка

- Визуально проверены все 11 слайдов PDF. Lint: нет переполнений и замечаний по правилам дизайна.
- Доменные проверки покрывают v1/v2, плотность, создание нового примера, повторное открытие и изоляцию сотрудников.
- Исправлен устаревший вход теста конкурентного создания: агенту теперь передаётся реальный документ; запрет создания без содержания сохранён и проверяется отдельно.
- Локальные MCP/HTTP проверки покрывают предложения, обратную связь и сохранение правок. Работа живой авторизованной модели не подтверждена.
- Браузерная проверка недоступна: ранее внутренний адрес был отклонён политикой браузера. Проверка файлов PDF не считается проверкой кликов, мобильного интерфейса или совместной работы в браузере.

## Что остаётся

Дизайн улучшен, но продукт ещё не завершён по enterprise PRD. Следующие крупные задачи: авторизованная агентная сессия с восстановлением после перезапуска; организации и наследуемые права папок; корпоративный Brand Onboarding и утверждённые эталоны; полная цепочка от источника до публикации; проверка мобильного редактирования и экспорта в целевом Office. Последовательность работ описана в предыдущих продуктовых документах.
