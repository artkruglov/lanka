# Корпоративный корпус v1

Это десять **учебных** брифов вымышленной компании, а не реальные интервью или доказательство спроса. cases.json содержит материалы, диапазон слайдов и вопросы проверяющему. Короткие, плотные, числовые, сравнительные, технические и английские задания не должны сводиться к одной композиции.

## Как провести проверку

1. Зафиксировать commit, выбранный дизайн/бренд, исполнителя и его версию. Начать с Focus 3; второй реальный бренд требует материалов и разрешения владельца. Не считать два встроенных оформления двумя корпоративными брендами.
2. Создать документ из интерфейса, загрузить materials и явно разрешить агенту их чтение. Передать brief без ручных координат и готовой раскладки.
3. Для refresh сначала сохранить исходный октябрьский отчёт как refresh.baseline.json. В нём вручную изменить заголовок обложки и расположение одного объекта. Затем поручить обновление по ноябрьскому источнику, сохраняя ручные правки.
4. Сохранить принятую автором копию FolderProject (объект со state) как CASE_ID.json в отдельную локальную папку результатов. Не коммитить корпоративные материалы или credentials. Прикрепить отдельно реальные журналы модели/действий и артефакты PDF/PPTX. Ручной или тестовый клиент обозначать явно.
5. Запустить:

```bash
node scripts/check-corporate-corpus.mjs /absolute/path/to/results out/corporate-corpus/report.json
```

Скрипт не создаёт презентации и не запускает модель. Отсутствующие/невалидные файлы, число слайдов, ссылки на несуществующие источники, диагностика дизайна и overflow проверяются автоматически. Для refresh дополнительно проверяются ID документа/слайдов, шаблон, заголовок обложки и существующие canvas-объекты с их геометрией. Проверка наличия материалов не доказывает использование их фактов. Правильность чисел, выводов, единиц и русского/английского текста оценивается отдельно.

Exit 1 означает неполный корпус или технические проблемы. Exit 0 означает только отсутствие этих проблем: отчёт всё равно содержит humanAccepted=false и awaiting-human-review. Не использовать его как сертификат качества или основание для автоматического promotion Focus 3.

## Человеческая приёмка

Просмотреть все слайды и оба экспорта. Зафиксировать для каждого: читаемость, иерархию, ритм, смысл визуалов, точность по материалам, удобство прямой правки/обсуждения/частичного принятия. Записывать замечание с номером слайда и конкретным примером, а не только общую оценку. Сохранить исходные замечания и последующие исправления.

Для цели 15/5 минут измерять полное время от начала работы с материалами до результата, принятого человеком, включая уточнения, ожидание, review и ручные исправления. Время одного model turn не равно этому показателю. Сравнить с реальным прежним способом подготовки на сопоставимом задании; один быстрый прогон не доказывает эффект для компаний.

Текущий базовый отчёт с пустой папкой результатов намеренно сообщает десять missing. Прогон этих десяти брифов настоящим агентом, второй бренд, Office и человеческая приёмка остаются открытыми.
