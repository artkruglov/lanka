# Lanka Studio 0.10.0 — public preview

Начните с README.md: запуск локального редактора, подключение агента и корпоративная установка описаны отдельно.

Это открытый предварительный выпуск под Apache 2.0, не сертификат промышленной готовности. Личные документы, переписка, ключи и база разработчика в репозиторий не входят.

Для работы нужны Node.js >=22.13 и npm; чат требует отдельной настройки PostgreSQL и разрешённого агента. См. RELEASE_NOTES.md и THIRD_PARTY_NOTICES.md.
